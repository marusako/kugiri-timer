# v1.2.0 — 自動アップデートとホイール式の時間設定

アプリが自分で新しいバージョンを確認して更新できるようになりました。あわせて、タイマーの動きと時間の設定方法を見直しました。

## ⚠️ 1.1.0 以前から更新する場合
アプリの内部 ID を変更したため、1.1.0 以前の版とは別のアプリとして扱われます。先に「設定 → アプリ」から古い Pomodoro Timer をアンインストールしてから、このバージョンをインストールしてください。設定と今日の完了回数は引き継がれます。

## 新機能
- **自動アップデート**：起動時に新しいバージョンを確認し、見つかったら画面上部でお知らせします。「更新する」を押すとダウンロードし、「再起動して更新」で新しいバージョンになります。タイマーが動いているときは、再起動の前に確認します。
- **ホイール式の時間設定**：作業・短い休憩・長い休憩の時間と、長い休憩までの回数を、iPhone のタイマーのようなホイールで選べるようになりました。マウスホイール・矢印キー・クリックでも操作できます。
- **テーマの切り替え**：自動（Windows の設定に合わせる）・ライト・ダークを選べるようになりました。

## 変更
- 作業や休憩が終わったとき、またはスキップしたときは、次のセッションが常に自動で始まるようになりました。止めたいときは一時停止を使ってください。これに伴い、「終わったら次を自動で開始」の設定はなくなりました。
- 設定の変更はすぐに反映・保存されるようになり、「保存」ボタンはなくなりました。始めたセッションの進み具合は消さず、新しい時間は次のセッションから使われます。
- ポータブル版（インストール不要の exe）の配布を終了しました。自動アップデートに対応しているインストーラー版をお使いください。

## ダウンロード
`pomodoro-timer-Setup-1.2.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
