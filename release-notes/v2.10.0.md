# v2.10.0 — Android 版（試作版）

Android 版の試作版を作りました。この Release の `kugiri-timer-2.10.0.apk` から入れられます。パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます（パソコン版の動きは、ほとんど変わりません）。

## Android 版（試作版）
- パソコン版と同じ画面で、タイマー・カレンダー・記録・BGM（ノイズと環境音）などが使えます。
- タイマーの終わりに、Android の通知が届きます。アプリを裏にしているときや、画面を消しているときも届きます。最初に起動したときに、通知を許可してください。
- 新しい版が出ると、アプリを開いたときに「新しいバージョンがあります」と出ます。「更新する」を押すとブラウザーでダウンロードが始まるので、ダウンロードしたファイルを押して「インストール」を押してください（Google Play 以外から入れたアプリは、Android の決まりで自動では入れ替えられません）。設定は引き継がれます。

### 入れ方
1. Android のスマホのブラウザーで、この Release の `kugiri-timer-2.10.0.apk` をダウンロードします。
2. ダウンロードしたファイルを押します。「この提供元のアプリを許可」を求められたら、オンにします。
3. Google Play プロテクトの警告が出ることがあります。Google Play で配っていないためです。「詳細」→「インストールする」で入れられます。

### 試作版のため、できないこと・注意
- 全画面、曲・壁紙の取り込み、外部カレンダー、データの書き出し・読み込みは使えません。
- 最近使ったアプリの一覧からアプリを閉じると、端末によっては、タイマーの終わりの通知も届かなくなります。
- アプリを閉じている間は、次のセッションは自動で始まりません（アプリを開いたときに始まります）。
- 正確な時刻に通知を出すため、「アラームとリマインダー」の権限を使います（インストールしたときに自動で許可されます）。

## パソコン版の変更
- 画面の安全の決まり（Content Security Policy）に、Android 版が最新の版を確かめるための GitHub の API への問い合わせを足しました。パソコン版の画面からは問い合わせません。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.10.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：上の「入れ方」をご覧ください。
