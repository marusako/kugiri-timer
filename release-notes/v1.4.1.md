# v1.4.1 — カードを薄くしても文字を読みやすく

壁紙の上のカードを薄くしたときの、文字の読みやすさを改善しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 改善
- **文字の影**：カードの不透明度を下げると、文字のまわりにうっすら影が付くようにしました。影の色はテーマの背景色（ライトなら白っぽい色、ダークなら黒っぽい色）で、カードが薄いほど濃くなります。暗い壁紙にライトテーマ、明るい壁紙にダークテーマを組み合わせても、時刻やボタンの文字が読めます。
- タブ・ラベル・統計の薄い色の文字は、カードが薄いほど濃い色で表示します。
- カードの不透明度が初期値の 72% 以上のときは、これまでと同じ見た目です。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.4.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
