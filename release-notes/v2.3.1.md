# v2.3.1 — 使い勝手の改善

小さな使い勝手の改善です。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 変更
- **毎週の時間割の ×**：一覧の × は、毎日・平日などのくり返す予定と同じく、その日だけ休みにするようにしました（ほかの週は残ります）。すべての週から消すときは、フォームの「すべての回を削除」か「この曜日をすべて消す」を使います。
- **予定の一覧**：タイマー（プリセット）を選んでいない予定には、「タイマー: 今の設定のまま」の行を出さないようにしました。
- **壁紙の削除**：曲と同じく、確認せずに消すようにしました。取り込み元の画像ファイルは消えないので、また取り込めます。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.3.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
