# v2.3.1 — タイマーを見やすく・Android 版はスワイプで再生バーを開け閉め

タイマーの残り時間を円の真ん中に大きく出すようにしました。Android 版では、再生バーとキューをスワイプでも開け閉めできるようになりました。Android 版はこの Release の `kugiri-timer-2.3.1.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **タイマーの表示**：残り時間を円のちょうど真ん中に置き、字を一回り大きくしました。モード（作業・休憩）と今の時刻は、その少し下にまとめました。

## Android 版（試作版）
- **スワイプで開け閉め**：閉じている再生バーを上へスワイプすると、再生中の画面が開きます。キューのつまみは、上へスワイプで開き、下へスワイプで閉じます。これまでどおり、押しても開け閉めできます。
- 閉じている再生バーの ▶ を、画面の右端から少し離して押しやすくしました。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.3.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.3.1.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.1.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
