# v2.4.0 — 予定ごとの集中の記録

予定ごとに、どれだけ集中できたかを記録するようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **予定ごとの集中の記録**：
  - タイマーモードで作業（Focus）を数えている間、その時刻にやっている予定に、数えた分数を記録します。作業を最後まで終えると、回数も 1 増えます（スキップした作業は回数に入りません）。
  - カレンダーの予定と毎週の時間割のコマのどちらも対象です。くり返す予定は、その日の回ごとに記録します。予定が重なっているときは、どの予定にも記録します。
  - カレンダーの一覧の各予定に「集中 50 分・2 回」、その日の見出しの下に「この日の予定で集中: 75 分・3 回」と出します（記録があるときだけ）。
  - 記録は、今日から 3 か月前の日まで残します。予定を消すと、その記録も消えます。記録はパソコンの中だけに保存し、どこにも送りません。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.4.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
