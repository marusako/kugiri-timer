# v2.3.0 — 再生バーを YouTube Music のように

BGM の再生バーを、YouTube Music の再生バーと同じ使い方に作り直しました。バーを押すと「再生中の画面」が開き、大きなジャケットとキュー（再生の順番の一覧）を見られます。Android 版はこの Release の `kugiri-timer-2.3.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **ジャケット**：取り込んだ曲のファイルの中にジャケットの絵があれば、再生バーと再生中の画面に出します（MP3 と M4A）。絵がない曲は音符、ノイズは波の記号になります。Windows やスマホの「再生中」の表示にもジャケットを渡します。
- **再生中の画面**：上に残り時間とモード（作業・休憩）を小さく出すので、開いている間もタイマーの時間が分かります。曲を選ぶ・並べ替える・プレイリストを切り替える・ノイズに切り替えるのは、ここのキューから行います（これまでの再生リストの小窓は、この画面にまとめました）。
- 再生バーの 2 行目に、流しているプレイリストの名前（ノイズのときは「BGM」）を出します。

## パソコン版
- 再生バーの並びを YouTube Music と同じにしました：左に前へ・▶ / ⏸・次へと経過時間、真ん中にジャケットと曲名、右に音量・リピート・シャッフル・▲。
- ▲ や曲名のあたりを押すと、再生バーの上に再生中の画面が開きます（左に大きなジャケット、右にキュー）。▼・Esc で閉じます。ウィンドウの幅が狭いときは、キューをジャケットの下に並べます。

## Android 版（試作版）
- 再生バーを、ジャケット・曲名・▶ だけの細いバーにしました。
- バーを押すと、全画面の再生中の画面が下から出てきます。大きなジャケット・再生位置・シャッフル・前へ・▶・次へ・リピートが並び、一番下の「キュー」を押すと一覧が上がってきます。
- 再生中の画面は、下へスワイプ・∨・「戻る」で閉じます。「戻る」は、キュー → 再生中の画面の順に閉じます。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.3.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.3.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.1.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
