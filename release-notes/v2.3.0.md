# v2.3.0 — くり返す予定とタイマーの設定パネル

カレンダーの予定をくり返せるようにし、タイマーの設定をメイン画面から開けるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **くり返す予定**：
  - 予定のフォームの「くり返し」で「この日だけ / 毎日 / 平日（月〜金） / 毎月〇日 / 毎週〇曜日」を選べます。毎月は、その日がない月（31 日など）は飛ばします。
  - くり返す予定には「終わりの日」を入れられます。空なら終わりなく続きます。
  - 一覧の × は、くり返す予定ならその日だけ休みにします（ほかの日は残ります）。フォームの「この日だけ休む」でも同じことができ、毎週の時間割のコマもその日だけ休めます。すべての日から消すときは「すべての回を削除」を使います。
- **タイマーの設定パネル**：右上のタイマーのボタンから、プリセットと時間（作業・短い休憩・長い休憩・回数）を開けるようになりました。設定画面の「タイマー」タブはなくなり、設定画面は「サウンド」から開きます。時間割モードでは、このボタンは出ません。

## 変更
- **この日をすべて消す / この曜日をすべて消す**：
  - 「この日をすべて消す」（その日の予定の見出しの横）は、その日の予定だけを消します。くり返す予定と毎週の時間割は、その日だけ休みになり、ほかの日・週は残ります。
  - 「この曜日をすべて消す」（時間割の欄）は、その曜日の毎週の時間割を、すべての週から消します。
- **ほかの曜日にコピー**：その日だけの予定も、同じ週（月曜始まり）のほかの曜日の日にコピーできるようになりました。毎週の時間割は、今までどおり毎週のその曜日にコピーします。
- **今の時刻**：タイマーモードでも、タイマーの下に今の時刻を出すようにしました。時間割モードの時刻とあわせて、文字を少し大きくしました。
- **プリセット**：デフォルトのプリセットから「学校」をなくし、「定番」と「長め」の 2 つにしました。「学校」を選んでいた予定は「今の設定のまま」になります。

## 直したこと
- 「まとめて作る」を「この日だけ」で使った日に、「ほかの曜日にコピー」と「この曜日をすべて消す」が押せなかった
- 毎週の時間割だけの日を、選んだ日だけまとめて消せなかった

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.3.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
