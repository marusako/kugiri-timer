# v1.6.4 — 通知を押すとアプリが前に出るように

作業・休憩が終わったときの通知から、すぐにアプリへ戻れるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 改善
- **通知を押すと、アプリが前に出る**ようになりました。最小化しているときは元の大きさに戻し、ほかのウィンドウの裏に隠れているときは手前に出します。

## お知らせ
- 通知が出ないときは、Windows の「設定 → システム → 通知」で、通知と Pomodoro Timer がオンになっているか、「応答不可」がオフになっているかを確かめてください。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.6.4.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
