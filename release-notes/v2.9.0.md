# v2.9.0 — Android 版のロック画面にタイマーと曲を出す

Android 版で、ロック画面にタイマーの残り時間と流している曲を出せるようにしました。あわせて、再生中の画面の操作を直し、音量の調整と、メイン画面の表示を見直しました。Android 版はこの Release の `kugiri-timer-2.9.0.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## Android 版
- **ロック画面にタイマーと曲を出す**：BGM を選んでいる間は、ロック画面と通知に、音楽アプリと同じ形の曲の板（曲名・前へ・▶ / ⏸・次へ）を出します。
  - 曲名の下の行に、タイマーの様子を出します（動いていれば「作業 · 12:34」と減っていき、止まっていれば「作業 · 25:00」、途中で止めたら「作業 · 12:34 · 一時停止」）。ラウンドの間は、ラウンドの作業・休憩を出します。画面を消していても、区切りの時刻が来ると次に切り替わります。
  - BGM を選んでいないときは、タイマーが動いている間だけ、別の通知で残り時間を出します。
  - ロック画面のボタンで、曲を止める・流す・次へ・前へができます。
- **曲を流している間は、裏にあっても止められにくく**：曲を選んでいる間は、通知を出す代わりに Android にアプリを止められにくくする仕組み（フォアグラウンドサービス）で動きます。画面を消したり、ほかのアプリを使ったりしていても、次の曲に進みやすくなります（端末によっては、それでも止まることがあります）。
- **キューは操作の並びの上に重ねる**：再生中の画面でキューを開くと、操作の並び（前へ・▶・次へなど）の上にかぶさり、一覧を操作しやすくなりました。
- **再生中の画面を動かす間は、再生バーをそのままに**：指で再生中の画面を開け閉めしている間は、閉じた再生バーを元の場所に残し、その上を画面が動きます。閉じた再生バーを下へ動かしても、バーが沈まなくなりました。左上の ▼ や「戻る」で閉じるときも、画面が下がって消えます。

## パソコン版・Android 版
- **音量の差を大きく**：音量の数字（0〜100）を 2 乗した大きさで鳴らすようにしました（50 で今までの 25%、20 で 4%）。数字の差が、聞いて分かる差になります。曲・BGM・アラーム・SE のすべてに使います。同じ数字でも、前の版より小さく聞こえるので、必要なら上げてください。
- **メイン画面の統計の行をなくす**：タイマーの下の「今日 N 回・ラウンド N/4」の行と、設定の「統計を表示」をなくしました（コマのまとまりの「ラウンド」と紛らわしかったため）。集中の時間と回数は、今までどおりカレンダーの「記録」で見られます。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.9.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`kugiri-timer-2.9.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
