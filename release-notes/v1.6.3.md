# v1.6.3 — 再生リストから BGM（ノイズ）を選べるように

再生バーの再生リストから、BGM（ノイズ）も選んで流せるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **再生リストの「音楽 / BGM」タブ**：再生リストの上のタブで、取り込んだ曲（音楽）と BGM（ホワイト・ピンク・ブラウンノイズ）を切り替えられます。BGM タブでノイズを押すと、そのノイズに切り替えて流します。BGM はプレイリストには入れられません。再生リストを開いたときは、今選んでいるもの（曲か BGM か）のタブが開きます。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.6.3.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
