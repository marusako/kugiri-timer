# v2.14.1 — 言語の並びを整える

設定の言語の一覧を、一般的な順番に並べかえました。Android 版はこの Release の `kugiri-timer-2.14.1.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **言語の並び**：設定の「一般」タブの言語の一覧を、Deutsch・English・Español・Français・Русский・සිංහල・简体中文・繁體中文・日本語・한국어 の順にしました。それぞれの言語での名前で、ラテン文字（ABC 順）→ キリル文字 → その他の文字 → 中国語・日本語・韓国語の順です。選んでいる言語は変わりません。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.14.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.14.1.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.11.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
