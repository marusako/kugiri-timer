# v1.4.0 — 多言語対応・全画面表示・音と見た目の設定の追加

画面の言語を選べるようになったほか、全画面表示や、音・見た目の細かい設定を追加しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **多言語対応**：画面の言語を日本語・English・한국어 から選べます（General タブ）。初めて起動したときは Windows の言語に合わせます。
- **全画面表示**：右上のボタンか F11 キーで切り替えます。Esc でも全画面を抜けられます（設定パネルが開いているときは、先にパネルを閉じます）。
- **画面サイズに合わせた自動調整**：ウィンドウの大きさに合わせて、タイマー全体が拡大・縮小します。全画面では画面に収まる範囲で大きく表示し、幅を狭めてもボタンの文字が改行しません。
- **マスター音量**：Alarm・BGM・SE の 3 つをまとめて上げ下げできます。実際の音量は「Master × それぞれの音量」です。
- **アラームの種類**：終了時の音を Chime・Bell・Digital・Marimba の 4 種類から選べます。選ぶとその場で試聴できます。
- **カードの不透明度**：壁紙の上のすりガラスのカードの透け具合を、0〜100% で調整できます（Appearance タブ）。
- **統計の表示切り替え**：メイン画面の Today / Round の行を、表示するか隠すかを選べます（General タブ）。隠していても、完了回数の記録は続きます。
- **Sound 設定の初期化**：Sound タブのボタンで、音量とアラームの音を初期値に戻せます。押すと確認が出ます。BGM の選択はそのまま残ります。

## 変更
- 画面の言語は Windows の言語に合わせて決まります。Windows が日本語の場合、これまで英語だった見出しやボタンが日本語で表示されます。英語に戻したいときは、General タブで「English」を選んでください。
- これまでの設定はそのまま引き継がれます。新しい設定は初期値（マスター音量 100、アラームの音 Chime、カードの不透明度 72%）から始まるので、音量や見た目は更新前と変わりません。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.4.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
