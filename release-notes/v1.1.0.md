# v1.1.0 — 自動開始と音量調整

タイマーが終わったあとの動きと、チャイムの音量を設定できるようになりました。

## ⚠️ このバージョンについて
このバージョンには自動アップデートの機能がありません。新しい機能を使うには、1.2.0 以降をお使いください。1.2.0 以降はアプリの内部 ID が変わっているため、このバージョンをアンインストールしてからインストールしてください（設定と今日の完了回数は引き継がれます）。

## 新機能
- **自動開始**：作業や休憩が終わったら、次のセッションを自動で始められるようになりました。設定でオン / オフを切り替えられます（初期値はオフ）。
- **音量調整**：終了時のチャイムの音量を 0〜100 で調整できるようになりました。0 で消音になり、「試聴」ボタンで保存前に音を確かめられます。

## 改善・修正
- アプリを 2 つ同時に起動できないようにしました。2 つ目を起動すると、開いているウィンドウが前面に出ます。以前は、2 つ目のウィンドウで設定や記録を読み書きできませんでした。
- 範囲外の設定値や壊れた保存データを、自動で補正するようにしました。

## ダウンロード
- `Pomodoro Timer Setup 1.1.0.exe`：インストーラー版（ユーザー単位でインストール、管理者権限は不要）
- `Pomodoro Timer 1.1.0 Portable.exe`：インストール不要の単体 exe（デスクトップ通知が出ない場合があります）

GitHub がファイル名のスペースを別の文字に置き換えて表示することがあります。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
