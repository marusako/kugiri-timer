# v2.8.1 — Android 版の使い勝手の改善

Android 版の画面と操作を直しました。パソコン版の動きは変わりません。Android 版はこの Release の `kugiri-timer-2.8.1.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## Android 版
- **全画面をやめました**：上の帯（時刻・電池）と下の帯（ナビゲーション）を隠さずに出します。帯の文字の色は、アプリのテーマ（ライト / ダーク / 自動）に合わせて読みやすい色になります。
- **上の帯のあたりをすりガラスに**：壁紙を選んでいるときは、画面の上に、下へいくほど消えるすりガラスを重ねます。明るい壁紙でも、帯の文字と右上のボタンが読みやすくなります。濃さはカードの不透明度に合わせて変わります（帯が読めるように、薄くなりすぎないようにしています）。
- **上へのスライドで開く**：閉じた再生バーを上へスライドすると、再生中の画面が開きます。キューのつまみは、上へで開き、下へで閉じます。どれも今までどおりタップでも開け閉めできます。画面の一番下から始めたスライド（ホームに戻る操作）では開きません。
- **再生バーの音量ボタンを消しました**：音量はスマホの音量ボタンで変えてください。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.8.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`kugiri-timer-2.8.1.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
