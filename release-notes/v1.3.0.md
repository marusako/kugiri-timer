# v1.3.0 — 壁紙・BGM・新しい設定画面

壁紙と BGM を追加し、作業する空間を自分好みに整えられるようになりました。1.2.0 をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **壁紙**：Dawn・Ocean・Forest・Night・Paper の 5 種類から選べます。手持ちの画像（PNG・JPEG・WebP・GIF）を取り込むこともできます。壁紙を設定すると、タイマーがすりガラスのカードに乗り、どんな壁紙でも文字を読みやすく表示します。
- **BGM**：White・Pink・Brown Noise を内蔵しました。手持ちの音声ファイル（MP3・WAV・OGG・M4A）を取り込むこともできます。BGM は Focus の間だけ流れ、休憩や一時停止で止まります。
- **3 つの音量**：音量を Alarm（終了時のチャイム）・BGM・SE（ボタンの操作音）に分けて調整できるようになりました。それぞれ「Test」で試聴できます。

## 変更
- 設定を画面全体に重なるパネルにし、Timer・Sound・Appearance のタブに分けました。設定欄がウィンドウに収まらず、スクロールが必要だった問題も解消しています。
- 見出し・ボタン・ラベルを英語表記にしました。通知や案内の文章は日本語のままです。
- 以前の音量の設定は、Alarm の音量として引き継がれます。

## 取り込んだファイルについて
取り込んだ画像と音声は、アプリの保存フォルダーにコピーして使います。元のファイルを移動・削除しても使い続けられます。また、アプリから削除しても元のファイルは消えません。

## ダウンロード
1.2.0 をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.3.0.exe` を実行してください。
