# v2.4.1 — 今の時刻を読みやすく

タイマーの下の今の時刻を読みやすくしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 変更
- **今の時刻の見た目**：薄い灰色の細い文字だったため、壁紙の上などで読みにくくなっていました。ライトなら黒、ダークなら白の文字色を 85% の濃さで、少し太い文字にしました。タイマーモードと時間割モードの両方に効きます。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.4.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
