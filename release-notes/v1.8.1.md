# v1.8.1 — 取り込んだ曲が多いときの表示の改善

設定画面で、取り込んだ曲が多いときも見やすくしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 改善
- 設定の「サウンド」タブで、取り込んだ曲を枠の中にまとめました。曲が多いときは、枠の中だけをスクロールして見られます。「なし」・ノイズ・「取り込む…」ボタンは、いつも枠の外に見えています。
- 音量を動かしたり曲を選んだりしても、曲の一覧のスクロール位置はそのままです。曲を取り込んだ直後は、取り込んだ曲が見える位置までスクロールします。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-1.8.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
