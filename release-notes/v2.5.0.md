# v2.5.0 — 保存データのファイル化と、書き出し・読み込み

設定や予定などを 1 つのファイル（data.json）に保存するようにし、バックアップの書き出しと読み込みができるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **書き出し・読み込み**：設定の General タブに「書き出し」「読み込み」を追加しました。
  - 書き出しでは、設定・今日の回数・予定・時間割・集中の記録を、1 つの JSON ファイルにまとめて保存します。初めの保存先はドキュメントフォルダーで、名前は `kugiri-timer-backup-<日付>.json` です。
  - 読み込みでは、選んだファイルの中身を確かめてから、確認のうえで今のデータと入れ替え、画面を読み込み直します。このアプリのファイルでないもの・壊れたファイルは「このファイルは読み込めません」と出て、データは変わりません。
  - 取り込んだ曲と壁紙のファイルは含まれません。

## 変更
- **保存のしかた**：これまでアプリの内部（localStorage）に保存していたデータを、保存フォルダー（`%APPDATA%\kugiri-timer`）の `data.json` に保存するようにしました。人が読める JSON の形です。
  - 書いている途中で電源が切れても、元のファイルが壊れない書き方にしています。読めない data.json があったときは、上書きする前に別の名前で残します。
  - 更新して初めて起動したときに、これまでのデータを data.json に写します。設定や記録はそのまま引き継がれます。これまでのデータも消さずに残します。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.5.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
