# v2.8.0 — ラウンドの間に、カードをめくって通常のタイマーを使う

ラウンドの間に、タイマーのカードをめくって、通常のタイマーと入れ替えられるようにしました。Android 版はこの Release の `kugiri-timer-2.8.0.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **カードの裏返し**：ラウンドの間だけ、カードの右上の「めくれた角」のボタンか、カードの左右の端を押すと、カードがめくれて、ラウンドのタイマー（表）と通常のタイマー（裏）が入れ替わります。
  - 裏では、スタート・一時停止・リセット・スキップ・タイマーの長さの変更が、今までどおり使えます。表に戻しても、通常のタイマーは裏で動き続けます。
  - 裏を見ている間は、角の印がモードの色になります。
  - ラウンドが終わると通常のタイマーの表示に戻り、次のラウンドはラウンドのタイマーから見せます。
  - BGM のノイズは、めくってもラウンドの作業・休憩に合わせます。
  - 「アニメーションを減らす」設定にしているときは、回る動きなしで入れ替わります。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.8.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`kugiri-timer-2.8.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
