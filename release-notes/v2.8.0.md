# v2.8.0 — 外部カレンダー（Google カレンダーなど）の取り込み

Google カレンダーなどの予定を、アプリのカレンダーに取り込めるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **外部カレンダーの取り込み**：カレンダーのタブの一番下にある「外部カレンダー」の欄に、カレンダーの「iCal 形式のアドレス（URL）」を貼り付けると、予定を読み取り専用で取り込みます。
  - Google カレンダーの場合：パソコンのブラウザーで Google カレンダーを開き、設定 → 取り込みたいカレンダー → 「カレンダーの統合」にある「iCal 形式の非公開 URL」をコピーします（スマホのアプリでは表示されません。学校・会社のアカウントでは、管理者の設定で出せないことがあります）。
  - 名前を付けて、5 つまで登録できます。起動したとき・30 分ごと・「今すぐ更新」を押したときに読み直します。つながらないときは、前に読めた予定を使います。
  - 取り込んだ予定も、自分で作った予定と同じく、開始・終了の通知、開始時のタイマーの準備（今の設定のまま）、メイン画面の「次の予定」、集中の記録に使います。アプリでは編集・削除できません。
  - 終日の予定は、カレンダーの一覧に「終日」として出すだけで、通知などには使いません。日付をまたぐ予定は、始まった日の 23:59 までとして扱います。
  - Google の API やログインは使っていないので、Google のアカウントのパスワードなどをアプリに入れる必要はありません。

## 安全のために
- 非公開 URL を知っている人は、誰でもそのカレンダーの予定を読めます。ほかの人に見せないでください。漏れたときは、Google カレンダーの設定でリセットできます。
- アプリは URL を、この PC の中で暗号化して保存します。保存データの書き出しのファイルには入れません（ほかの PC に移したときは、URL を貼り直してください）。

## そのほか
- 予定のファイル（.ics）の読み取りに ical.js（Mozilla Public License 2.0）を使っています。一般タブのクレジットに書きました。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.8.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
