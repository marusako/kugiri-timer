# v1.8.0 — タイマーの文字のフォントを選べるように

タイマーの数字（残り時間）のフォントを、6 種類から選べるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **タイマーの文字**：設定の「外観」タブで、残り時間の数字のフォントを選べます。標準（以前と同じ）・細字・極太・角ばった字・等幅・明朝風の 6 種類で、それぞれのフォントで書いた見本から選べます。どれも Windows に最初から入っているフォントです。
- どのフォントでも、時刻が変わるたびに数字の幅が変わって表示が揺れないものを選んでいます。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-1.8.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
