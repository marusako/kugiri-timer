# v2.2.0 — カレンダーと時間割を 1 つの画面に

カレンダーと時間割を 1 つの画面にまとめ、「まとめて作る」を使いやすくしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 変更
- **カレンダーと時間割を 1 つの画面に**：「カレンダー / 時間割」のタブをなくしました。月のカレンダーで日を選ぶと、その日だけの予定と、その曜日の毎週の時間割が、1 つの一覧に並びます。一覧からそのまま編集・削除できます。
- **予定の追加**：「＋ 予定を追加」で「この日だけ / 毎週〇曜日」を選べます。
- **まとめて作る**：
  - 初めは、選んだ日だけに作ります。「毎週〇曜日」を選ぶと、毎週の時間割として作ります。
  - 昼休みのような「長い休み」を、何コマ目のあとに入れるかを指定できるようになりました。
  - 初めの値を 8:30 開始・1 コマ 45 分・7 コマ・休み 10 分・長い休み 60 分（4 コマ目のあと）にしました（8:30〜15:35）。一度作ると、次からは最後に作ったときの値になります。
- 「ほかの曜日にコピー」「この曜日をすべて消す」「予定の前に知らせる」は、一覧の下の「時間割」の欄にまとめました。どれも選んだ日の曜日に効きます。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.2.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
