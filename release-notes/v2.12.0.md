# v2.12.0 — Android 版で外部カレンダーと書き出し・読み込みを使えるように

Android 版（試作版）を、スマホで使いやすいように調整しました。外部カレンダーと、データの書き出し・読み込みも使えるようになりました。Android 版はこの Release の `kugiri-timer-2.12.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## Android 版（試作版）
- **外部カレンダー**：パソコン版と同じく、Google カレンダーなどの「iCal 形式の非公開アドレス」を登録して、予定を取り込めるようになりました。アドレスは Android の鍵の仕組み（Keystore）で暗号化して保存し、書き出しのファイルには入れません。アドレスは、スマホの Chrome で Google カレンダーを「PC 版サイト」にして開き、設定 → カレンダー → カレンダーの統合 からコピーできます。
- **データの書き出し・読み込み**：設定の「データ」から使えるようになりました。書き出しは共有の画面で、ドライブや「ファイル」アプリなどに送れます。ファイルの形はパソコン版と同じなので、パソコン版で書き出したファイルを Android 版で読み込むことも、その逆もできます。
- **最初から全画面**：上と下の帯を隠し、カメラのまわりまで画面を広げました。帯は、画面の端からスワイプすると少しのあいだだけ出ます。
- **「戻る」の操作**：Android の「戻る」（画面の端からのスワイプ）で、開いている画面を 1 つずつ閉じるようにしました。メイン画面で戻るとアプリが裏に回ります。長押しと、何もないところのタップで戻る動きはなくしました。
- **タイマーを大きく**：タイマーを大きくし、リセットとスキップのボタンを記号（↺・⏭）にしました。
- **再生バー**：曲を選んでいなくても「BGM 未選択」と出し、▶ から曲を選べるようにしました。ボタンを少し上げて押しやすくしました。
- **タイマーの文字**：6 種類の文字を、パソコン版の見た目に近づけました（似た形のフォントを入れています）。
- タップしたときに出ていた青い枠を出さないようにしました。

## パソコン版
- 外部カレンダーの仕組みを Android 版と共通にしました。動きは変わりません。
- 外部カレンダーの説明の「この PC」を「この端末」にしました。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.12.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.12.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.11.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
