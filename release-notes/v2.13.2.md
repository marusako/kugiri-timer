# v2.13.2 — 再生バーのボタンを大きく

再生バーのボタンの記号を一回り大きくし、ボタンどうしの間隔を広げて押しやすくしました。Android 版はこの Release の `kugiri-timer-2.13.2.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **再生バーのボタン**：前へ・▶ / ⏸・次へ・音量・リピート・シャッフル・▲ の記号を一回り大きくし、ボタンどうしの間隔を広げました。
- Android 版の再生中の画面でも、シャッフル・前へ・▶・次へ・リピート・音量のボタンを大きくしました。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.13.2.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.13.2.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.11.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
