# v1.3.1 — BGM の続きから再生と新しい操作音

BGM と操作音を改善しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 改善
- **BGM の続きから再生**：取り込んだ曲を BGM にしているとき、一時停止や休憩のあとに再開すると、曲が最初に戻っていました。止めたところから続きを再生するようにしました。曲を別のものに変えたときは、新しい曲を最初から再生します。
- **操作音（SE）**：ボタンを押したときの音を、丸くやわらかい「ポンッ」という音に変えました。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.3.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
