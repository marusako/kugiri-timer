# v2.7.0 — Focusr に名前を変更・起動モーション・Android のアイコン

アプリの名前を「Kugiri Timer」から「Focusr」に変えました。起動したときの短い動きと、Android 版のアイコンも加えました。Android 版はこの Release の `kugiri-timer-2.7.0.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **名前の変更**：アプリの名前を「Focusr」にしました。ウィンドウ・スタートメニュー・アプリの一覧・Android のホーム画面に出る名前が変わります。設定・予定・記録・取り込んだ曲や壁紙は、そのまま引き継がれます。Release のファイル名（kugiri-timer-…）は今までどおりです。
- **起動モーション**：起動したときに、タイマーの円が一周描かれて「Focusr」の文字が出る、約 1.2 秒の動きを加えました。「アニメーションを減らす」設定にしているときは出ません。
- **カードの透明度**：外観タブの「カードの不透明度」を 0% にすると、すりガラスのぼかしも消えて、完全に透明になるようにしました（100% で不透明）。

## Android 版
- **アイコン**：Capacitor の初めのアイコンから、パソコン版と同じ時計のアイコンに変えました。端末の形（丸・角丸など）に合わせて切り抜かれ、Android 13 以降のテーマ アイコンにも対応しています。

## パソコン版
- スタートメニューのショートカットとアプリの名前が「Focusr」に変わります。タスクバーにピン止めするときは、この版に更新したあとで、スタートメニューの「Focusr」を右クリックして「タスクバーにピン留めする」を選んでください。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.7.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`kugiri-timer-2.7.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
