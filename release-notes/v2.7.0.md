# v2.7.0 — 時間割モードをなくし、毎週のコマも予定と同じに

カレンダーとタイマーで足りるようになったため、時間割モードをなくしました。そのかわりに、毎週の時間割のコマも、カレンダーの予定と同じように知らせます。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 変更
- **時間割モードをなくしました**：左上の「タイマー / 時間割」の切り替えと、時計どおりに残り時間を数える画面、予定の区切りごとのアラームがなくなりました。時間割モードを選んでいた場合も、更新後はタイマーの画面で起動します。
- **毎週のコマも予定と同じに**：毎週の時間割のコマでも、次のことを行うようにしました。
  - 始まりと終わりに Windows の通知を出します。
  - 始まりの時刻に、タイマーが止まっていれば作業の頭に準備します（スタートは自分で押します。コマには時間の組み合わせ（プリセット）を選ぶ欄がないので、今の設定のままです）。
  - メイン画面の「予定中 / 次の予定」の 1 行に出します。
- **予定の前に知らせる**：カレンダーの予定と毎週のコマの両方に効くようにしました。設定は、カレンダーのタブの一番下に移しました（選んでいた値はそのまま引き継ぎます）。
- 同じ時刻に予定の終わりと次の予定の始まりがあるときは、「終わりました」→「始まりました」の順に知らせます。

## そのまま使えるもの
- 毎週の時間割のコマ、「まとめて作る」「ほかの曜日にコピー」「この曜日をすべて消す」は今までどおり使えます。
- 予定ごとの集中の記録と、記録の画面も今までどおりです。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.7.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
