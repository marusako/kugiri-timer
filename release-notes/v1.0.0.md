# v1.0.0 — 最初のリリース

最初のリリースです。

## ⚠️ このバージョンについて
このバージョンには自動アップデートの機能がありません。新しい機能を使うには、1.2.0 以降をお使いください。1.2.0 以降はアプリの内部 ID が変わっているため、このバージョンをアンインストールしてからインストールしてください（設定と今日の完了回数は引き継がれます）。

## 機能
- 作業 / 短い休憩 / 長い休憩の自動切り替え（4 回作業ごとに長い休憩）
- スタート / 一時停止 / リセット / スキップ（Space キーでスタートと一時停止）
- 終了時のチャイム音とデスクトップ通知
- 作業・休憩の時間と、長い休憩までの回数の変更
- 今日の作業完了回数の記録

## ダウンロード
- `Pomodoro Timer Setup 1.0.0.exe`：インストーラー版（ユーザー単位でインストール、管理者権限は不要）
- `Pomodoro Timer 1.0.0 Portable.exe`：インストール不要の単体 exe（デスクトップ通知が出ない場合があります）

GitHub がファイル名のスペースを別の文字に置き換えて表示することがあります。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
