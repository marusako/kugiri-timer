# v2.3.3 — カレンダーの予定の追加と設定を、下の引き出しにまとめる

カレンダーの画面を、月の表と選んだ日の予定の一覧だけにして見やすくしました。予定の追加とカレンダーの設定は、画面の下の引き出しから開きます。Android 版はこの Release の `kugiri-timer-2.3.3.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **下の引き出し**：カレンダーの画面の下に「＋ 予定を追加」と「カレンダーの設定」のボタンを置きました。押すと、それぞれの板が下から上がってきます。
  - **予定を追加**：予定のフォームと、毎週の時間割の補助（まとめて作る・ほかの曜日にコピー・この曜日をすべて消す）。
  - **カレンダーの設定**：予定の前の知らせと、外部カレンダー。
- 一覧の予定を押すと、「予定を追加」の板で編集できます。保存・取り消し・削除・この日だけ休むのあとは、板が閉じます。
- 板は ∨・Esc で閉じます。Esc はもう一度押すとカレンダーの画面も閉じます。Android 版では、「戻る」と、下の段を下へスワイプでも閉じられます。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.3.3.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.3.3.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.1.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
