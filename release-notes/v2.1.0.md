# v2.1.0 — Android 版で曲と壁紙を取り込めるように

Android 版（試作版）で、曲と壁紙を取り込めるようにしました。Android 版はこの Release の `kugiri-timer-2.1.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます（パソコン版の動きは変わりません）。

## Android 版（試作版）
- **曲・壁紙の取り込み**：設定の外観タブ（壁紙）とサウンドタブ（曲）の「取り込む」で、スマホの写真や音楽ファイルを選べるようになりました。取り込んだものはアプリの中にしまうので、元のファイルを消しても使い続けられます。アプリを更新しても残りますが、アンインストールすると消えます。
- **更新のお知らせ**：「更新する」を押したときに、APK のダウンロードではなく、この Release のページを開くようにしました。ページの `kugiri-timer-<版>.apk` を押してダウンロードし、ダウンロードしたファイルを押して「インストール」を押してください（前の版では、ダウンロードが終わっても「ダウンロードしています…」の表示が変わらないことがありました）。

### 2.0.0 から更新するとき
2.0.0 の「更新する」は APK のダウンロードを直接開きます。ダウンロードの表示が変わらないときは、その画面を閉じて、「ファイル」アプリの「ダウンロード」から `kugiri-timer-2.1.0.apk` を開いてください。

## パソコン版
- 取り込んだファイルの名前の付け方を、Android 版と共通にしました。動きは変わりません。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.1.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.1.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
