# v2.1.0 — 時間割を入れやすく

時間割を、まとめて作ったり、ほかの曜日にコピーしたりできるようにしました。予定の前に知らせる通知も追加しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **まとめて作る**：カレンダーの「時間割」タブで、開始時刻・1 コマの長さ・休みの長さ・コマ数を入れると、その曜日に「1限」「2限」…をまとめて作れます（名前はあとから変えられます）。作る前に、何時から何時まで何コマできるかを表示します。
- **ほかの曜日にコピー**：選んでいる曜日の時間割を、ほかの曜日にまとめてコピーできます。
- **予定の前に知らせる**：時間割モードで、予定が始まる 1・3・5・10 分前に「あと 3 分で英語」と通知できます（初めは「しない」です）。

## お知らせ
- 「まとめて作る」と「ほかの曜日にコピー」は、その曜日の時間割を置き換えます。すでに時間割がある曜日では、置き換える前に確認します。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.1.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
