# v2.4.2 — 環境音を消す

BGM の環境音（雨・波・風・焚き火・心音）の 5 つを消しました。Android 版はこの Release の `kugiri-timer-2.4.2.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **環境音**：雨・波・風・焚き火・心音の 5 つを消しました。BGM のノイズは White Noise・Pink Noise・Brown Noise の 3 つになります。あとの版で、録音した「雨音」「焚火」を足す予定です。
- 環境音を BGM に選んでいた場合は、更新後に BGM が「なし」に戻ります。ほかの BGM を選び直してください。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.4.2.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.4.2.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.1.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
