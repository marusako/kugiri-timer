# v1.6.0 — BGM の再生バーと再生リスト

メイン画面に BGM の再生バーを追加し、取り込んだ曲を再生リストとして続けて流せるようにしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **BGM の再生バー**：BGM を選んでいるときは、画面の下に再生バーが出ます。前へ・再生 / 一時停止・次へ、曲名と経過時間、再生位置（クリックで移動）、リピート（オフ → 全曲 → 1 曲）、シャッフル、音量をここで操作できます。ノイズのときは、前へ・次へ・再生位置は使えません。
- **再生リスト**：取り込んだ曲を、最後まで流れたら次の曲へ自動で進めます。バーの再生リストのボタンで一覧を開き、曲を押して再生したり、ドラッグ（または Alt + ↑ / ↓）で並べ替えたりできます。今流れている曲には印が付きます。
- **メディアキー**：キーボードの再生 / 一時停止・前へ・次へのキーと、Windows の音量表示に出る再生操作で、BGM を操作できます。

## 改善
- BGM は今までどおり作業中だけ流れます。再生バーの一時停止で止めると、作業中でも再生ボタンを押すまで流れません（アプリを閉じると元に戻ります）。
- 再生バーが出ている間は、タイマーが少し小さくなり、バーと重ならないようにしました。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `pomodoro-timer-Setup-1.6.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
