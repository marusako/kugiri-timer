# v2.0.0 — 時間割モード

学校の時間割のように、曜日ごとの予定に合わせて時計どおりに動く「時間割モード」を追加しました。これまでのタイマーは「タイマーモード」として、そのまま使えます。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新機能
- **モードの切り替え**：メイン画面の左上で、「タイマー」と「時間割」を切り替えられます。選んだモードは次に起動したときも続きます。初めはタイマーモードです。
- **時間割**：カレンダーの「時間割」タブで、曜日ごとに毎週くり返す時間（名前・開始・終了）を登録できます。登録した時間は、カレンダーの日の一覧にも「毎週」の印付きで表示されます。
- **時間割モード**：スタートを押さなくても、時計どおりに自動で数えます。
  - 予定の最中は、その予定が終わるまでの残り時間と名前を表示します。
  - 予定と予定の間は「休み時間」として、次の予定までの残り時間を表示します。
  - 下に次の予定を表示します。その日のカレンダーの予定も合わせて数えます。
  - 予定の始まりと終わりで、アラームを鳴らして通知します。
- ノイズの BGM は、時間割モードでは予定の最中に流れ、休み時間に止まります。

## お知らせ
- 時間割モードに切り替えると、動いているタイマーは一時停止します。
- 通知は、アプリが起動している間だけ出ます。スリープから戻ったときなどに 5 分より前に過ぎていた区切りは、通知しません。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.0.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
