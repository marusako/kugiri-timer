# v2.8.2 — Android 版の通知と、再生中の画面の操作の改善

Android 版で、画面を消している間の通知と、再生中の画面・キューの操作を直しました。パソコン版の動きは変わりません。Android 版はこの Release の `kugiri-timer-2.8.2.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## Android 版
- **画面を消していても、2 回目からの通知が届く**：前の版では、画面を消している間は、今のセッションの終わりの通知しか来ず、次のセッションはアプリを開いたときに始まっていました。
  - タイマーが動いている間は、先の 8 回分の終わりの通知をまとめて予約します。通知には、次に何が始まったかを書きます。
  - アプリを開き直すと、時刻どおりに進んでいたものとして、表示・完了の回数・集中の記録が追いつきます（8 回分まで）。
  - ラウンドのコマ・カレンダーの予定の始まりと終わり、「あと N 分」の知らせも、この先 24 時間ぶんを予約するので、画面を消していても届きます。
- **再生中の画面とキューが、指について動く**：閉じた再生バーを上へ動かすと、再生中の画面が下から指について上がります。開いた画面を下へ、キューのつまみを上下に動かしても、指について動きます。離したところで、大きく動かしたか速く払ったら開け閉めし、足りなければ元に戻ります。今までどおり、押すだけでも開け閉めできます。
- **再生バーとキューのつまみを、下の帯の上に**：「ホームに戻る」の白い線と重ならないように、再生バーと閉じたキューのつまみを、下の帯の上に上げました。閉じたキューのつまみも太くして、つかみやすくしました。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.8.2.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`kugiri-timer-2.8.2.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
