# v2.9.1 — 中の名前を Focusr にそろえる

アプリの中で使っている名前を、前の名前（kugiri-timer）から Focusr にそろえました。見た目と使い方は変わりません。Android 版はこの Release の `focusr-2.9.1.apk` から、パソコン版はアプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **ファイルの名前**：Release に置くファイルの名前を `focusr-…` にしました（パソコン版のインストーラーは `focusr-Setup-2.9.1.exe`、Android 版は `focusr-2.9.1.apk`）。2.9.0 までの Android 版のアプリが更新を見つけられるよう、しばらくは同じ APK を `kugiri-timer-2.9.1.apk` の名前でも置きます。
- **データの書き出し**：書き出すファイルの名前を `focusr-backup-<日付>.json` にしました。前の名前で書き出したファイルも、今までどおり読み込めます。
- **変わらないもの**：設定・予定・記録・取り込んだ曲や壁紙は、そのまま引き継がれます。保存の場所も変わりません。

## ダウンロード
- パソコン版：2.6.1 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `focusr-Setup-2.9.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：アプリの更新のお知らせから、この Release のページを開けます。`focusr-2.9.1.apk` をダウンロードして開きます（`kugiri-timer-2.9.1.apk` も中身は同じです）。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。
