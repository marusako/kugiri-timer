# v2.6.0 — ラウンドのタイマー

ラウンドの間は、タイマーが時計に合わせて自動で進むようにしました。Android 版はこの Release の `kugiri-timer-2.6.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **ラウンドのタイマー**：ラウンドの最初のコマが始まってから最後のコマが終わるまで、カードにラウンドのタイマーを出します。コマの間は「作業」でそのコマの終わりまで、コマとコマの間は「休憩」で次のコマの始まりまでの残り時間です。カードの下の行には「ラウンドの名前 · コマの名前」を出します。
- ラウンドの間は、スタート / 一時停止・リセット・スキップ・タイマーの長さの変更はできません（ボタンは「ラウンド中」になります）。音楽と BGM は操作できます。
- 作業と休憩が切り替わるたびに、アラームが鳴ります。コマを最後まで終えると、今日の完了回数と、そのコマの集中の回数が増えます。ラウンドの作業の時間は、集中の記録に数えます（通常のタイマーと重なる時間は 1 回だけ）。
- コマの開始時刻には、通常のタイマーを準備せず、知らせだけを出すようにしました（カレンダーの予定は今までどおり準備します）。
- Android 版では、画面を消している間は、切り替わりのアラームとコマの知らせが遅れて、画面をつけたときに出ます。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.6.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.6.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.1.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
