# v2.6.0 — 集中の記録を見る画面

週・月ごとに、どれだけ集中できたかを振り返れる画面を追加しました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 新しい機能
- **記録の画面**：カレンダーのパネルに「カレンダー / 記録」の切り替えを追加しました。記録のタブでは、次のものが見られます。
  - 週（月曜始まり）・月ごとの、集中した時間の合計と、作業を終えた回数
  - 日ごとの棒グラフ（縦軸付き）。棒を押す・マウスを乗せると、その日の時間と回数が出ます
  - 前の週・月との差（「先週より +40 分」など）
  - 前後の週・月への移動と、「今週 / 今月」に戻るボタン
  - 一番下に、記録のしかた（何を・いつ数えるか）の説明
- **予定がない時間の作業も記録**：これまでは予定の最中の作業だけを記録していましたが、予定がない時間の作業も、日ごとの合計として記録するようにしました。予定が重なっていても、二重には数えません。

## 注意
- 日ごとの合計は、この版に更新してから記録を始めます。そのため、前の版で作業した分は記録の画面の合計に入りません（予定ごとの記録は、今までどおりカレンダーの一覧で見られます）。
- 記録はパソコンの中だけに保存し、どこにも送りません。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.6.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
