# v2.14.0 — 7 つの言語を追加

中国語（簡体字・繁体字）・スペイン語・フランス語・ドイツ語・ロシア語・シンハラ語を追加し、10 の言語から選べるようになりました。Android 版はこの Release の `kugiri-timer-2.14.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **言語**：日本語・English・한국어 に加えて、简体中文・繁體中文・Español・Français・Deutsch・Русский・සිංහල を、設定の「一般」タブで選べるようになりました。
- 初めて起動したときは、Windows・Android の言語に合わせて選びます。中国語は、地域が台湾・香港・マカオなら繁体字、それ以外なら簡体字になります。
- 英語などでは、「BGM」「SE」という略語の代わりに、その言語の言葉（英語は Background / Effects など）で表示するようにしました。日本語・韓国語・中国語は今までどおり「BGM」です。
- 追加した 7 つの言語の訳は、その言語を話す人による確認がまだです。不自然なところがあれば、お知らせください。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.14.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.14.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.11.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
