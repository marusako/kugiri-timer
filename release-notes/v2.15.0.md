# v2.15.0 — 予定とラウンドを分ける

カレンダーで、予定と、コマ（授業など）をまとめた「ラウンド」を、タブで分けて扱えるようにしました。Android 版はこの Release の `kugiri-timer-2.15.0.apk` から、パソコン版は 1.2.0 以降をお使いの場合、アプリの自動アップデートで更新できます。

## パソコン版・Android 版
- **予定とラウンドのタブ**：カレンダーで選んだ日の一覧を、「予定」と「ラウンド」のタブで切り替えます。下の引き出しのボタンも、選んだタブに合わせて「＋ 予定を追加」「＋ ラウンドを追加」になります。
- **ラウンド**：続けて行うコマのまとまりです。前の「まとめて作る」で、名前を付けて「この日だけ」か「毎週」のラウンドを作ります。一覧ではラウンドの下にコマが並びます。
  - ラウンドを押すと、名前の変更・コマを足す・この日だけ休む・削除ができます。
  - コマを押すと、名前と時刻を直せます。
  - ほかの曜日へのコピーと、この曜日の毎週のラウンドを消す道具は、ラウンドのタブの引き出しにあります。
- **今までの時間割**：曜日ごとに、名前のない毎週のラウンドにまとめて引き継ぎます。集中の記録も残ります。
- 予定のくり返しから「毎週〇曜日」を外しました。毎週のものは、ラウンドで作ります。前の版で「その日だけ」でまとめて作ったものは、予定のまま残ります。

## Android 版
- 画面を切って曲を流しているときに、次の曲に入ると止まってしまう問題を直しました（直ったかどうかは、まだ実機で確かめていません）。
- 再生バーとキューは、タップで開くようにしました。上へのスワイプで開くのはやめました（アプリを閉じる操作で開いてしまうため）。閉じるのは、今までどおり下へのスワイプでもできます。

## ダウンロード
- パソコン版：1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.15.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- Android 版：スマホのブラウザーで `kugiri-timer-2.15.0.apk` をダウンロードして開きます。「この提供元のアプリを許可」や Google Play プロテクトの警告が出たら、「詳細」→「インストールする」で入れられます。2.11.0 からは、アプリの更新のお知らせからこの Release のページを開けます。
