# v2.1.1 — 使い勝手の改善

予定や曲を消すときの手間を減らし、時間割モードとボタンを見やすくしました。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 改善
- **消すときの確認をなくしました**：カレンダーの予定、時間割の時間、取り込んだ曲は、× を押すとすぐに消えます（取り込んだ曲は、取り込み元のファイルが残るので、もう一度取り込めます）。
- **時間割をまとめて消す**：カレンダーの「時間割」タブに「この曜日をすべて消す」を追加しました。まとめて消えるので、これだけは確認します。
- **今の時刻の表示**：時間割モードで残り時間を数えているときは、予定の名前の下に小さく今の時刻を表示します。
- **ボタンの輪郭**：リセット・スキップ、右上の丸いボタン、モードの切り替えなどに、文字と同じ色の細い線を付けて、ボタンの形を分かりやすくしました。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-2.1.1.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
