# v1.7.0 — アプリ名を「Kugiri Timer」に変更

アプリ名を「Pomodoro Timer」から「Kugiri Timer」（区切り）に変えました。「Pomodoro」は商標の持ち主のガイドラインで、許可なくアプリ名に使うことが認められていないためです。機能は変わりません。1.2.0 以降をお使いの場合は、アプリの自動アップデートで更新できます。

## 変更
- **アプリ名を「Kugiri Timer」に変更**：ウィンドウのタイトル、スタートメニューのショートカット、インストーラーの名前などが新しい名前になります。
- **GitHub のリポジトリ名を変更**：`marusako/pomodoro-timer` から `marusako/kugiri-timer` に変わりました。古い URL は新しい URL に転送されます。

## 設定・記録の引き継ぎ
- 自動アップデートで更新すると、設定・完了回数・取り込んだ壁紙と BGM・プレイリストを、そのまま引き継ぎます。
- 保存フォルダーは `%APPDATA%\pomodoro-timer` から `%APPDATA%\kugiri-timer` に変わります。新しい版を初めて起動したときに、古いフォルダーの内容を新しいフォルダーにコピーします。古いフォルダーは予備として残します。新しい版で問題がなければ、消してもかまいません。
- アプリは上書きで更新され、「Pomodoro Timer」と「Kugiri Timer」が二重にインストールされることはありません。

## ダウンロード
1.2.0 以降をお使いの場合は、自動アップデートで届きます。新しくインストールする場合は `kugiri-timer-Setup-1.7.0.exe` を実行してください。ユーザー単位でインストールされ、管理者権限は不要です。コード署名をしていないため、初回に Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
